# firstslackbot
## OVERVIEW
This is my very first slack bot I made by following a NASA Stardance Challenge Guide. It has a help command (/sandhanabot-help) that shows the user the available functions, a ping command (/sandhanabot-ping), which shows the user the latency, and finally a daily space image command (/sandhanabot-spaceimage) which shows NASA's Image of the Day and its associated explanation.
